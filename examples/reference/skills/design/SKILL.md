# Product interface

Create a complete runnable project for the configured framework.

- Use a restrained, product-specific visual system with semantic color and spacing tokens.
- Make the primary workflow immediately usable instead of returning a marketing-only shell.
- Cover loading, empty, error, success, disabled, hover, focus-visible, and responsive states.
- Use semantic HTML, explicit labels, keyboard-accessible controls, and reduced-motion behavior.
- Keep generated source maintainable and return every file required to install and run it.
